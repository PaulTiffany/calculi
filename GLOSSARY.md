## Starting words

| Word | Plain-language meaning |
|---|---|
| calculus / calculi | *Calculi* is the plural. The word covers familiar mathematics of rates and accumulation, formal rule systems, and several specialized extensions. It has no single sharp boundary across all uses. |
| model | A chosen description of a situation, including what it tracks and the rules it uses |
| assumption | Something taken as given for an argument or model |
| formal | Having precisely stated expressions and rules |
| object | Something the system works with: a number, statement, record, process, or other defined item |
| rule | An allowed way to form, transform, or reason about the objects |
| function | A rule assigning an output to each allowed input |
| integer | A number with no fractional part, such as −3, 0, or 4 |
| constraint | A restriction on which choices are allowed |

## Amounts, space, and steps

| Word | Plain-language meaning |
|---|---|
| rate | Change in one quantity per unit change in another, such as liters per minute |
| net change | Final value minus starting value |
| limit | The value approached as an input or approximation approaches a specified condition |
| derivative | A local rate defined by a limit, when it exists |
| integral | An accumulation under a specified rule; in elementary calculus, often a limit of sums |
| differential equation | An equation relating an unknown function to one or more of its derivatives |
| multivariable | Having several inputs that can vary |
| vector | A quantity with size and direction; more abstract definitions extend this picture |
| field | An assignment of a quantity to each point of a space |
| optimization | Finding the best allowed choice for a stated goal |
| stationary | Having a zero first derivative or first variation in the relevant setting; this alone does not establish a maximum or minimum |
| functional | A rule taking a function as input and returning a number |
| discrete | Described in separate steps or values |
| sequence | Values in a chosen order |
| finite difference | A difference between values at specified steps |
| numerical method | A computational method for finding or approximating a mathematical answer |
| percentage point | A unit for the difference between percentages: 80% to 70% is a drop of ten percentage points |

## Reasoning, programs, and data

| Word | Plain-language meaning |
|---|---|
| proposition | A statement treated as true or false in the elementary setting used here |
| predicate | A property or relation that can be applied to objects |
| quantifier | A word or symbol such as “all” or “there exists at least one” |
| inference | A step from assumptions or earlier claims to a conclusion |
| proof | A chain or tree of justified steps establishing a conclusion from assumptions |
| counterexample | An example showing that a proposed general claim fails |
| sequent | A formal record of what is derivable from a collection of assumptions |
| type | A classification that helps govern which expressions may be formed or combined |
| precondition | A condition required before a program step |
| postcondition | A condition promised after a program step, under the stated interpretation |
| relation | In relational databases, a set of tuples with the specified fields |
| tuple | An ordered collection of values; pictured as a database record |
| query | A question expressed for a data system to answer |
| declarative | Stating what conditions an answer must meet rather than prescribing every execution step |

## Interaction, chance, and cause

| Word | Plain-language meaning |
|---|---|
| process | An actor or activity described by a formal model |
| concurrency | Activities being in progress over overlapping periods |
| deadlock | A state where the relevant activities cannot proceed because they are blocked |
| fluent | A property or value that can depend on time or situation |
| persistence | A fact continuing to hold when the rules specify no relevant change |
| probability | A number describing chance within a probability model, between zero and one |
| independent | For events, learning that one occurred does not change the probability of the other; richer collections require further conditions |
| stochastic process | A family of random quantities indexed by time or another parameter |
| random walk | A path built from random steps |
| causal model | A model stating how variables affect one another |
| intervention | Setting a variable through an action rather than merely observing its value |

## Words found in optional tracks

| Word | Meaning in the relevant track |
|---|---|
| coordinates / components | Numbers describing a point or quantity relative to chosen directions and units |
| basis | A set of independent directions used to describe vectors; each vector has a unique combination of them |
| tensor | A multilinear mathematical object; its component descriptions obey specified transformation rules when a basis changes |
| differential form | An alternating covariant tensor field, suited to integration over oriented paths, surfaces, or higher-dimensional regions |
| orientation | A consistent choice of direction or sign for a path or region |
| complex number | A number of the form $a+bi$, where $a$ and $b$ are real and $i^2=-1$ |
| contour | A path used for integration, here in the complex plane |
| fractional order | A possibly noninteger order of integration or differentiation, within a specified definition |
| operator | A map acting on mathematical objects such as vectors or functions |
| identity operator | The operator that returns each input unchanged |
| linear assumption | An assumption whose use must be accounted for under linear proof rules, without free duplication or discarding |
| abstraction | In lambda calculus, forming an expression with a named input |
| application | Applying one lambda term to another |
| reduction | A rewrite using the chosen system's rules |
| normal form | An expression with no further rewrite of the specified kind available |
| name | In process calculi, an entity used in communication structure; definitions vary |
| reflection | A system working with representations of its own expressions or processes |
| bisimulation | A relation matching observable behavior step by step, under a specified definition |
| encoding | A formal translation with stated properties it preserves |
| distinction graph | Goertzel's graph recording pairwise indistinguishability for a chosen observer |
| bounded observer | A source-specific construction in Tiffany's observation framework; its exact components belong to that source |
| residue in complex analysis | The coefficient of $(z-a)^{-1}$ in a function's local Laurent expansion about an isolated singularity $a$ |
| residue in the Tiffany track | A specified mismatch in observation, reconstruction, or transport; it is a different source-specific use of the word |
| holonomy | The effect of transporting something around a closed loop; a precise use requires a specified transport rule |

A familiar word can have different technical meanings in different fields. Always check the local definition.
